# pyTgBot

Данный проект представляет собой скрапер бота для Telegram, который показывает цену валют и погоду в городах

# Использованные библиотеки

Для разработки данного бота были использованы такие библиотеки как:

- [pyTelegramBotAPI](https://pypi.org/project/pyTelegramBotAPI/)
- [requests](https://pypi.org/project/requests/)
- [beatifulsoup4](https://pypi.org/project/beautifulsoup4/)
- [transliterate](https://pypi.org/project/transliterate/)
